# セッションの表示名と差分の閲覧

## セッションタイトル

最初の実質的な依頼で、本作業に入る前に `<絵文字1つ> <短い日本語のタイトル>` の形式で設定する。対象と目的が分かる24文字程度までの日本語の名詞句にし、内容を表す絵文字を1つ選ぶ。分類しにくい場合は `✨` を使う。

リンク先を読まないと主題が分からない場合は、確認してから具体的な題名を付ける。仮の題名を付けた場合は、主題が分かった時点で更新する。

- Orcaでは `orca worktree current --json` で既存名を確認する。日本語やチケット識別子を含む名前は上書きしない。日本語を含まない英語の自動生成名や、ブランチと同じ名前は更新する。
- Orcaの設定コマンドは `orca worktree set --worktree current --display-name '<絵文字> <タイトル>' --json`。
- Herdrでは `herdr-title '<絵文字> <タイトル>'`。更新は `--force` を付ける。
- 両方使える場合は両方設定する。利用できない環境では省略する。
- Orcaでは設定後に `orca worktree current --json` の `displayName` を確認し、指定した日本語と絵文字が反映されたことを確かめる。

## コード差分を画面で見る

ユーザーがコード差分の画面表示を求めた場合に `difit` を使う。内部の比較や検索は `git diff` を使う。

`difit`、`difit HEAD`、`difit <base> HEAD`、`difit --pr <PR URL>` を必要に応じて選び、詳細は `difit --help` で確認する。

バックグラウンドで起動し、URLを伝える。既定のブラウザ自動起動と、タブを閉じたときの終了を使う。
